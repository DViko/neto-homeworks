# Memo: Shallow Copy, Deep Copy

## Проблема по умолчанию:

### Shallow Copy:

```cpp
    arr = new_array;
```

>
>### C++ выполняет поверхностное копирование, копируется только указатель `_data`, оба объекта владеют одной и той же памятью
>

### К чему это приводит:

>
>### Изменения в одном объекте влияют на другой. Два объекта владеют одной памятью. При уничтожении `delete[]` вызывается  дважды (double free / undefined behavior)
>

---

## Deep Copy:

```cpp
    arr = new_array;
```

>
>### C++ выполняет глубокое копирование, создаётся новая область памяти, данные копируются, каждый объект владеет своей памятью
>

### К чему это приводит:

>
>### Изменения в одном объекте не влияют на другой. Каждый объект управляет своим ресурсом. При уничтожении delete[] вызывается корректно для каждого объекта
>

## Ключевая идея:

>
>### Один объект = одна область памяти
>### Никогда не делить владение `“сырым”` указателем между объектами без контроля
>

---

## Итог

### Shallow Copy (поверхностное копирование):

>
>### `shared` указатель, `double free`, `undefined behavior`
>

### Deep Copy (глубокое копирование):

>
> ### Каждый объект владеет своей памятью. Нет shared-ресурсов без контроля. Программа работает предсказуемо и безопасно
>
