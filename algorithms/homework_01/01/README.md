# 🧠 **Домашняя работа_01_01: Сложность алгоритма**

```cpp
int calc(int *arr, int size)
{
    int ans = 0;

    for (int i = 1; i < size; i++)
    {
        ans += arr[i] - arr[i - 1];
    }

    return ans;
}
```

> ### Функция имеет два входных параметра, указатель на массив ***arr*** и длину массива ***size***. В теле функции один линейный цикл без вложенности. Цикл линейно проходит по элементам массива заранее известной длины. Каждая итерация цикла вычисляет разность текущего и предыдущего элементов массива, вычисляет сумму разностей всех элементов массива.
>
> ### Масштабируемым входным параметром является длина массива ***size***, в рамках анализа сложности ***n = size***. Цикл выполняется ***size - 1*** раз, при этом каждая итерация содержит константное количество операций. Время работы функции линейно зависит от размера входящего параметра ***size***. Сложность O(n).
>
> ### Функция не выделяет память, зависящую от size. Использует переменные ans и i, что является фиксированным количеством памяти независимо от n. Массив передаётся в функцию извне и не учитывается как дополнительная память алгоритма. Дополнительная память O(1).
>
> ### Асимптотика: Линейная временная сложность O(n), константная пространственная сложность O(1).
