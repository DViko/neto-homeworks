# 🧠 Домашняя работа 01_02. Поиск в массиве

<br>

```cpp
int arr[9]{14, 16, 19, 32, 32, 32, 56, 69, 72};


int search(const int arr[], int size, int target)
{
    int left = 0;
    int right = size;

    while (left < right)
    {
        int mid = left + (right - left) / 2;

        if (arr[mid] <= target)
        {
            left = mid + 1;
        }
        else
        {
             right = mid;
        }
    }

     return size - left;
}
```

> ### Функция имеет три входных параметра, ***arr***, ***size***, ***target***, работает с отсортированным массивом, что позволяет использовать метод бинарного поиска. Алгоритм корректен при условии, что массив отсортирован по возрастанию. В теле функции используется цикл while, с каждой итерацией диапазон поиска элементов массива сужается примерно в два раза. Каждая итерация выполняет вычисление среднего элемента диапазона, сравнение с искомым значением и сдвиг границы поиска.
>
> ### Масштабируемым входным параметром является размер массива ***size***, в рамках оценки сложности ***n = size***. Количество итераций цикла растёт логарифмически от ***n***, так как на каждом шаге рассматриваемый диапазон уменьшается вдвое. Каждая итерация содержит константное количество операций. Временная сложность функции O(log n).
>
> ### Функция не выделяет дополнительную память, зависящую от ***n***. Используются переменные left, right, mid и target, фиксированное количество памяти независимо от n. Массив передаётся извне и не учитывается в оценке сложности. Дополнительная память O(1).
>
> ### Асимптотика: Логарифмическая временная сложность O(log n), константная пространственная сложность O(1).
