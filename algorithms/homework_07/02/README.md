## Memo: Breadth-First Search (BFS)

### Описание:

> #### Программа выполняет обход графа в ширину (Breadth-First Search, BFS). Граф задаётся матрицей смежности размером `N × N`, где `N` — количество вершин графа. Алгоритм начинает обход с выбранной пользователем вершины и посещает сначала всех её соседей, затем соседей вершин уровнем ниже и так далее

### Псевдокод:

```cpp
    bfs(start_vertex):

        создать очередь

        пометить start_vertex как посещённую
        добавить start_vertex в очередь

        пока очередь не пуста:

            взять vertex из очереди
            вывести vertex

            для каждой vertex[adjacent]:

                если есть ребро (vertex, adjacent) и adjacent не посещена:

                    пометить adjacent как посещённую
                    добавить adjacent в очередь
```

> #### BFS использует очередь (FIFO). Сначала обрабатывается стартовая вершина, затем все её соседи. После этого обрабатываются вершины следующего уровня. Таким образом алгоритм проходит граф по слоям, постепенно удаляясь от начальной вершины

### Временная сложность

> #### Алгоритм BFS посещает каждую вершину графа один раз. Однако граф хранится в виде матрицы смежности `N × N`, поэтому при обработке каждой вершины необходимо проверить все N возможных связей. Таким образом для каждой из `N` вершин выполняется цикл длины `N` что дает сложность `O(N²)`
>
>#### Временная сложность: `O(N²)`

### Пространственная сложность

> #### Программа использует следующие структуры: Матрица графа, таблица `N × N`, содержащая информацию о наличии рёбер между вершинами, сложностью `O(N²)`. Массив посещённых вершин, используется для отметки уже посещённых вершин, чтобы алгоритм не обрабатывал их повторно, сложностью `O(N)`. Очередь BFS, используется для хранения вершин, ожидающих обработки. Максимальный размер очереди `N` что дает сложность `O(N)`. Доминирует в потреблении памяти матрица смежности
>
> #### Пространственная сложность: `O(N²)`

### Итоговая асимптотика:

> #### Время работы: `O(N²)`<br>Память: `O(N²)`
