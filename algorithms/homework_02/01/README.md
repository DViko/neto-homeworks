# Homework 02_01: Анализ сложности алгоритма


## Рекурсивная Фибоначчи с мемоизацией:

>
> ### В данном варианте используется рекурсивная функция с сохранением уже вычисленных значений в массиве. Благодаря этому функция не вычисляет одно и то же значение многократно, как это происходит в наивной рекурсивной реализации.
>
> ### В наивном рекурсивном временная сложность составляет O(2^n) из-за экспоненциального количества повторяющихся вызовов. С мемоизацией каждый элемент вычисляется только один раз, что снижает временную сложность до O(n).
>
> ### Пространственная сложность увеличивается от O(1) до O(n), за счёт массива memo для хранения вычисленных значений и рекурсивного стека вызовов, максимальная глубина которого также O(n).
>

## Временная сложность:

>
> ### Каждый индекс n обрабатывается только один раз. На каждом шаге выполняется константное количество операций.
>
> ### Сложность: O(n)
>

## Пространственная сложность:

>
> ### Массив memo для хранения вычисленных значений O(n). Рекурсивный стек вызовов (максимальная глубина n) O(n).
>
> ### Итоговая сложность O(n).
>
>

>
> ### Асимптотика: Временная сложность O(n), пространственная сложность O(n).
>
